# v1.0.1 release benchmark

Status: **fresh release validation pending**. Do not merge the version bump,
tag or publish while this record is incomplete. Earlier release results do
not substitute for v1.0.1 measurements.

The candidate includes Manrope typography, monitoring readability fixes and
updated Pingora/compression dependencies. The required experiment is the full
adaptive search for 5, 10, 20, 40, 80 and 100 MiB JSON, with at least three
fresh-pod trials per confirmed setting. Each trial uses two Gateway pods with
2 CPUs / 1 GiB memory / 512 MiB serialized-body budget per pod.

projects are active, so release measurement will use isolated native amd64
GitHub runners. A matched eight-slot, three-trial 5 MiB comparison will use
the same harness against the candidate and the immutable v1.0.0 amd64 image.
These are planned conditions, not benchmark results. The committed
runtime identity, resolved image, harness provenance, actual trial hardware,
raw evidence, failed trials, memory/headroom, latency, outcomes and resource
boundaries will be recorded after measurement.
