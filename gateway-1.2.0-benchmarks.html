Resource edges need production headroom. The 512 MiB byte budget counts admitted serialized body bytes. Total pod memory also includes connection state, parsers, buffers and allocator overhead. floor(512 / JSON MiB) is the complete-body arithmetic bound, not the configured-slot limit. Most requests may intentionally receive body/authentication 503 or source-limit 429. Earlier authentication/source admission can prevent body slots from filling; a stable setting is not proof that all configured slots were occupied.
Latency includes a 10-second upstream read pause and a 2-second post-upload delay; no latency SLO is imposed. Memory is the largest individual-pod observation. OOM peaks may be censored, and absent data is shown as unavailable. Compare runs on the same architecture and host resources.
